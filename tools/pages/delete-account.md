## 방법 1 — 앱에서 직접 삭제하기

앱에 로그인할 수 있다면 앱 안에서 바로 삭제할 수 있습니다.

- 앱 실행 → 하단 [내 정보] 탭
- [계정 설정] → [회원 탈퇴]
- 안내를 확인하고 [탈퇴하기]를 누르면 즉시 처리됩니다

## 방법 2 — 메일로 요청하기

앱을 이미 삭제했거나 로그인할 수 없다면 아래 주소로 메일을 보내주세요.

- 받는 사람: sihyunb88@gmail.com
- 제목: [부산 땅따먹기] 계정 삭제 요청
- 본문에 아래 두 가지를 적어주세요
- 가입하신 이메일 주소 (카카오로 가입하셨다면 '카카오 로그인'이라고 적어주세요)
- 앱에서 사용하던 닉네임

본인 확인을 위해 가입 정보와 대조한 뒤 처리합니다. 확인이 어려운 경우 추가 정보를 요청드릴 수 있습니다.

## 삭제되는 데이터

계정을 삭제하면 아래 데이터가 모두 삭제되며 복구할 수 없습니다.

- 계정 정보 — 이메일 주소, 비밀번호, 닉네임, 카카오 연동 정보
- 활동 기록 — 완료한 미션 내역, 찜한 미션, 구·군 점령 현황
- 보유 포인트 — 잔여 포인트는 즉시 소멸하며 환급되지 않습니다
- 인증 자료 — 미션 인증을 위해 업로드하신 사진과 영수증 이미지, 그리고 해당 인증에 사용된 위치 정보
- 랭킹 표시 — 전체·지역 랭킹에서 제외됩니다

## 보관되는 데이터

원칙적으로 모든 데이터를 삭제하지만, 아래는 예외적으로 일정 기간 보관합니다.

- 부정 이용(위치 조작, 사진 도용 등) 확인 이력 — 재가입 악용 방지를 위해 6개월
- 관계 법령에서 보존을 요구하는 기록 — 해당 법령이 정한 기간

보관되는 정보는 위 목적 외의 용도로 이용하지 않으며, 기간이 지나면 지체 없이 파기합니다.
